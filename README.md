## Short Introduction
This repository is dedicated to the third lab session of the Programming Fundamentals (PF) course. The primary focus of this lab is to understand how basic input/output operations work in C and how to handle conditional execution flow using decision-making statements.

> "First, solve the problem. Then, write the code." – John Johnson

---

## Lab Objectives
1. Understand the syntax and execution flow of decision-making structures.
2. Implement relational and logical operators to evaluate compound expressions.
3. Master formatted input and output using `scanf()` and `printf()`.

---

## C Topics Covered
* Format specifiers (`%d`, `%f`, `%c`)
* `if`, `else if`, and `else` conditional blocks
* Relational operators (`>`, `<`, `==`, `!=`)
* Logical operators (`&&`, `||`, `!`)
